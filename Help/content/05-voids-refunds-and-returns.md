# Voids, Refunds, and Returns

NLI-POS provides **Void Order** for an order. It does not provide a separate return, exchange, or refund transaction.

## Void an order

1. Select **Order** and find the order. **Expected result:** The matching order appears in the list.
2. Open the order details. **Expected result:** The order and its items are shown for review.
3. Confirm that you have the correct order and follow your store's approval procedure. **Expected result:** You are ready to void only the intended order.
4. Select **Void Order** and confirm the prompt. **Expected result:** The order is marked void and its sold stock is returned to inventory.

**Warning:** Voiding changes the order and stock records. NLI-POS does not provide an unvoid action. Process money returned to a customer according to your store's payment-provider procedure.

## Returns and refunds

There is no separate return or refund screen. If a customer returns an item or needs money returned, follow your store's procedure outside NLI-POS. Do not use **Void Order** unless the entire original order should be voided.

See [Making a Sale](/Help/making-a-sale) for order entry and [Receipts](/Help/receipts) for locating a transaction.
